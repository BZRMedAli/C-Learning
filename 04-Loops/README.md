  # Documentation:

 In the beginning of programming enginners found a problem to manipulate instructions lines used in a program, and sometime even

 respected, so here we will have conditions inside a loop, so the loops are very important  skills in programming

  # Loops:

  We have 3 types of loops:
  -for:Here the incrementation is automatic and for this loop we declare the starting point and the end with the steps at ones
  
  -while:Here the program execute this loop if only the condition is correct (satified) and here we should increment the variable
  inside while in the code while bloc
  
  -do...while:Here the program will execute this loop at least one time, and after that this loop is executed by the program while
  the condition defined in while section is satisfied
